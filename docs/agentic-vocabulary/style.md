# Style of the agentic skills

This document states the style conventions for the `fal-agentic-vocabulary` and `fal-agentic-audit` skills. The conventions for names also apply wherever other skills, such as the Japanese skills, refer to the names that the vocabulary skill defines.

For a question that these conventions do not cover, the [Google developer documentation style guide](https://developers.google.com/style) can serve as a reference.

## Register

The skill text uses no contractions and no second person. Both belong to a conversational register, and the skills keep a neutral register.

The text of the vocabulary skill, including the remedies that accompany an antipattern definition, contains no imperatives and no "should" or "must." Principles and antipatterns often conflict, and the agent that uses the skill weighs them in each case. A command or an obligation would discourage that weighing.

## Fixed phrases

In the vocabulary skill, the first sentence of a principle's section has the form "X requires that ...", as in "Necessity requires that anything added be worth its cost." The principle's name appears without its kind word, because the section heading has already stated the kind.

In the vocabulary skill, a principle's test is introduced by a sentence that begins with "The test is," so that the reader can find it.

## Names

A principle name begins with a capital letter. An antipattern name begins with a lowercase letter. A bias name is lowercase in the prose, as in the additive bias.

A name is bold where it is defined and not bold where it is referred to. Nothing other than a name at its definition is bold.

The sentence that defines an antipattern also introduces its name, so the name appears with its kind word: The **"vestige"** antipattern is ...

A reference to a name carries its kind word:

- An antipattern name is in double quotation marks, as in the "vestige" antipattern.
- A principle name needs no quotation marks, because the capital letters mark its extent, as in the Necessity principle.

A construction that states the kind can replace the kind word, as in the sentence of an audit cue that begins with "Suspect" and lists antipattern names in quotation marks.

An antipattern name can appear without quotation marks and kind word only where it has already appeared with its kind word in the same passage. How far a passage extends depends on the text, and a paragraph is typical. The definition paragraph of another antipattern is a separate passage.

A heading that names a principle or an antipattern shows its kind. A principle's heading has the form `Principle of X`, with nothing else, as in the sections of the vocabulary skill. An antipattern's heading has the form `The "x" antipattern`, as in the judgment notes of the audit skill.

A group heading of the vocabulary skill is not a name, so it is not bold, carries no kind word, and is not referred to from the prose.

A name in parentheses is written so that the parentheses do not cause the "unstated relation" antipattern. For example, the name carries its kind word, as in (the "vestige" antipattern).

A word that matches a name but is used as an ordinary noun is outside these conventions.

## Typography

Quotation marks mark a term being introduced and a word discussed as a word. Italics are not used, because CJK scripts have no italic form. Quotation marks correspond to the Japanese 「」, so a Japanese translation keeps them.
